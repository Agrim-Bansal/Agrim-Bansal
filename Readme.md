## Featured Projects

### Artemis
* **Tech Stack:** Kotlin, Jetpack Compose, QWEN, Flux
* **Overview:** A cutting-edge Android application designed to integrate Ai into the workflow of photo editors. Capable of running on low compute devices without compromising latency. With an additional focus on privacy by being local first, the app was designed to streamline photo editing and allow beginners to leverage AI and create stunning edits without the learning curve. It was designed as a part of the Inter IIT Tech Meet 14 (yr 2025) Adobe Problem Statement.

### Sportshub IIT Delhi
* **Tech Stack:** React, TypeScript, TailwindCSS, Firebase
* **Overview:** A comprehensive sports management platform developed for the Inter Hostel Sports General Championship at IIT Delhi. I designed and engineered the frontend to provide a unified platform for scheduling, results tracking, and real-time updates across multiple sports and hostels, significantly enhancing the user experience for participants and organizers alike. Built with DevClub x BSA IIT Delhi.

### [Can You Beat Sherlock?](https://github.com/Agrim-Bansal/can-you-beat-sherlock)
* **Tech Stack:** React, TypeScript, TailwindCSS, Gemini API
* **Overview:** An immersive, AI-driven detective game leveraging Generative AI for dynamic, natural-language interrogations. Engineered to handle complex state management and real-time AI API interactions.
* **Links:** [Repository](https://github.com/Agrim-Bansal/can-you-beat-sherlock) | [Live Demo](https://can-you-beat-sherlock.vercel.app/)

### [Stock Simulator](https://github.com/Agrim-Bansal/Stock-Simulator)

* **Overview:** A comprehensive stock market simulation platform featuring real-time data synchronization, virtual portfolio management, and advanced trading analytics.

### [BrainEffInterpreter](https://github.com/Agrim-Bansal/BrainEffInterpreter)
* **Tech Stack:** Python for Terminal app. Vanilla HTML, CSS, JavaScript for web interface
* **Overview:** A highly interactive, step-by-step execution engine and memory visualizer engineered to parse, demystify, and execute the esoteric Brainfuck programming language.
* **Links:** [Repository](https://github.com/Agrim-Bansal/BrainEffInterpreter) | [Live Demo](https://agraim.github.io/BrainEffInterpreter/) 

### [Interactive Robotics (IITD CAIC GC)](https://github.com/Agrim-Bansal/InteractiveRobotics)
* **Tech Stack:** Python, ROS, CoppeliaSim, LLM APIs, Web Technologies
* **Overview:** Developed for the CAIC GC Robotics and Dev track at IIT Delhi. Engineered a comprehensive control system for an 8-DOF robotic arm within CoppeliaSim, implementing complex functionalities such as inverse kinematics, collision avoidance, and precise object manipulation (grabbing, lifting, placing). Architected multi-modal control access through a web application, terminal inputs, and an innovative LLM-powered voice interface, supplemented by predefined executable macros.
* **Links:** [Repository](https://github.com/Agrim-Bansal/InteractiveRobotics)

### [DigitalEnigma2026 (ACES ACM CTF)](https://github.com/Agrim-Bansal/DigitalEnigma2026)
